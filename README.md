# Handmade E-commerce Website

A multi-page website for showcasing and selling handmade products, built with HTML and CSS.

## Features
- Home page with handmade product showcase
- About page with the story behind the store
- Artists page introducing the creators
- Individual product pages with images
- Clean, simple layout

## Technologies Used
- HTML5
- CSS3
